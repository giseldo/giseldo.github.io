Este é o primeiro texto da nova área de blog. A partir de agora, as postagens são escritas aqui mesmo, em Markdown, e publicadas junto com o resto do site.

## Como criar uma nova postagem

No terminal, dentro da pasta do projeto:

```bash
hugo new post/minha-postagem.md
```

O arquivo nasce em `content/post/` como rascunho (`draft: true`). Quando terminar, troque para `draft: false` e faça o commit.

## O que vem a seguir

Substitua este texto pelo assunto que você quiser: basta editar `content/post/2026-11-02-primeira-postagem.md`.
